# MERN Authentication using OAuth

This project is a simple full-stack MERN (MongoDB, Express, React, Node.js) application that implements user authentication using OAuth. Users can log in via third-party authentication providers like Google, GitHub, or Facebook. The app securely manages authentication tokens and user sessions.

## Features

- OAuth-based authentication (Google, GitHub, Facebook)
- User session management with JWT (JSON Web Token)
- MongoDB for storing user information
- Secure password storage with bcrypt
- React frontend with protected routes
- RESTful API with Express.js
- Error handling and form validation

## Technologies Used

### Frontend
- React.js
- React Router for navigation
  
### Backend
- Node.js with Express.js
- MongoDB (using Mongoose for object modeling)
- Passport.js for OAuth integration
- JWT for session handling
- Bcrypt for password hashing
